ONE BIG IDEA. EIGHTY WAYS TO USE IT.

Good features
get better
with people.

People try something. We collect clues, hear different ideas, and make it better. When it helps, people return and invite others. Then we learn again.

Explore all 80 wheels ↓

Read each wheel clockwise from the top. “Data” means clues like feedback, a finished task, or something that went wrong. Growth is a possibility to test, not a promise.

THE SAME SIX STEPS CONNECT EVERY WHEEL
THE BIG LOOP

A useful feature creates clues. Better understanding improves the feature. More useful results give people a reason to return.

Grow it

If it helps, add the next useful part. A small team trial might become a longer project.

Make it simpler

If it feels hard or noisy, remove something. Fewer, better matches can help more.

Change direction

If people's needs change, change the feature too. Learn from what really happens.
